01 — Overview

What Does This App Do?

You type a mood or feeling — like "something funny but emotional" — and the app uses OpenAI's AI to understand the meaning of your words. It then searches 30 movies stored in PostgreSQL to find the ones whose descriptions are semantically closest to your mood, and returns the Top 3 with a % match score.

🔑 Key concept — Vector Embeddings: OpenAI converts text into a list of 1536 numbers (called a vector). Similar meanings produce similar vectors. The database finds movies whose vectors are closest to your mood vector using cosine similarity. This is how AI "understands" language.

05 — Database Context

AppDbContext.cs — Line by Line

The bridge between C# objects and PostgreSQL. Tells EF Core which C# class maps to which table and which property maps to which column.

MovieApi/Data/AppDbContext.csDatabase Layer
7public class AppDbContext : DbContextInherits from DbContext — the EF Core base class. This gives our class the ability to query the database, save changes, and run raw SQL.
9public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }Constructor. Receives database options (connection string, driver) from dependency injection and passes them to the EF Core base class. This is how the connection string from appsettings.json reaches EF Core.
11public DbSet<Movie> Movies => Set<Movie>();Declares the Movies table. DbSet<Movie> represents a table. You can query it like: _db.Movies.Where(...). Set<Movie>() returns the EF Core set for that entity type.
18entity.ToTable("movies");Critical mapping. EF Core defaults to PascalCase table name "Movies" but PostgreSQL uses lowercase "movies". This fixes that mismatch — without it, every query would crash with "relation Movies does not exist".
19–23entity.Property(m => m.Title).HasColumnName("title");Column name mapping. Same reason — EF Core defaults to PascalCase "Title" but the column is lowercase "title". Each property is explicitly mapped to its snake_case column name.
24–26entity.Property(m => m.Embedding).HasColumnName("embedding").HasColumnType("vector(1536)");Vector column setup. Maps the Embedding property to the vector(1536) column. The 1536 is the dimension size — OpenAI's text-embedding-3-small always produces exactly 1536 numbers per text input.
30–34modelBuilder.Entity<MovieQueryResult>(entity => { entity.HasNoKey(); });Keyless entity. MovieQueryResult is not a real table — just a C# class to hold results from the raw SQL cosine-similarity query. HasNoKey() tells EF Core "this is a result shape, not a real entity with a primary key."

MovieController.cs — Helper MethodsHelpers
GetEmbeddingAsyncEmbeddingClient client = _openAI.GetEmbeddingClient("text-embedding-3-small");Gets the embedding model client. text-embedding-3-small is the OpenAI model name — it converts text into 1536-dimensional vectors. Fast and cost-effective.
OpenAIEmbedding embedding = await client.GenerateEmbeddingAsync(text);Calls OpenAI API. Sends text over the internet to OpenAI servers. await means the code waits for the response without blocking the server thread.
return embedding.ToFloats().ToArray();Extracts the 1536 numbers. ToFloats() gets them as a span. ToArray() converts to a regular float[] array for use in our code.
ToVectorString"[" + string.Join(",", floats.Select(f => f.ToString("G", CultureInfo.InvariantCulture))) + "]"Formats for PostgreSQL. pgvector expects vectors as strings like [0.123,0.456,...]. InvariantCulture ensures decimals use . not , regardless of the server's regional settings.
MovieController.cs — POST /api/seedSeed Endpoint
[HttpPost("seed")]foreach (var (title, genre, description) in SeedMovies)Loops through all 30 hardcoded movies. Uses tuple deconstruction to get title, genre, description from each movie tuple.
if (await _db.Movies.AnyAsync(m => m.Title == title)) continue;Idempotency check. Runs SELECT EXISTS(...) in the DB. If a movie already exists, skip it. Makes the endpoint safe to call multiple times without duplicating data.
float[] floats = await GetEmbeddingAsync(description);Calls OpenAI. Sends the movie's description and gets back 1536 numbers representing its meaning. Takes ~0.3s per movie.
_db.Movies.Add(new Movie { ..., Embedding = new Vector(floats) });Creates a Movie object. new Vector(floats) wraps the float array into the Pgvector type that EF Core knows how to store in the vector(1536) column.
await _db.SaveChangesAsync();Writes to the database. EF Core generates INSERT INTO movies (...) VALUES (...) SQL and executes it. Called inside the loop so each movie is saved before moving to the next.
MovieController.cs — POST /api/recommendRecommend Endpoint
1if (string.IsNullOrWhiteSpace(req.Mood)) return BadRequest(...);Input validation. If the mood is empty, return HTTP 400 immediately. Prevents wasting an OpenAI API call on empty input.
2float[] floats = await GetEmbeddingAsync(req.Mood);Convert mood to a vector. Sends "funny with a twist" to OpenAI, gets back 1536 numbers representing that mood's meaning.
3var queryVec = new NpgsqlParameter("queryVec", vectorStr);Creates a SQL parameter. Using @queryVec instead of injecting the value directly into SQL prevents SQL injection attacks.
4SELECT title, genre, description, CAST(1 - (embedding <=> @queryVec::vector) AS FLOAT8) AS score FROM movies ORDER BY embedding <=> @queryVec::vector LIMIT 3The core AI search query. embedding <=> @queryVec = cosine DISTANCE (smaller = more similar). 1 - distance = cosine SIMILARITY shown as %. ORDER BY sorts by relevance. LIMIT 3 returns only top 3 matches.
5return Ok(rows.Select(r => new MovieResult(r.Title, r.Genre, r.Description, r.Score)));Returns results as JSON. Maps each DB row into a MovieResult DTO and sends HTTP 200. The frontend receives a JSON array of 3 movies with title, genre, description, and score.
