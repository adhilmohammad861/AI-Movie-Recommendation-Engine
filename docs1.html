A full-stack AI-powered application that understands your mood and recommends the perfect movie using vector embeddings and semantic similarity search.

⭐ View on GitHub 🚀 Quick Start
01 — Overview

What is this project?

The AI Movie Recommendation Engine lets users type a mood or vibe (e.g. "something funny with a twist ending") and instantly get semantically relevant movie recommendations. It uses OpenAI text embeddings to convert both the movie descriptions and the user's mood into mathematical vectors, then performs a cosine similarity search in PostgreSQL with the pgvector extension to find the best matches — no keyword matching, pure AI understanding.

03 — Features

Key Features

🧠

Semantic Mood Search

Type any mood or vibe in natural language. The AI understands meaning, not just keywords — "sad but hopeful" finds emotionally matching films.

📐

Vector Embeddings (1536 dimensions)

Every movie description is converted to a 1536-dimensional float vector using OpenAI's text-embedding-3-small model and stored permanently in PostgreSQL.

🎯

Cosine Similarity Ranking

Uses the pgvector <=> operator for cosine distance. Returns Top 3 matches with a % match score.

🌱

Auto Database Seeding

30 hardcoded movies are seeded automatically on first run. The POST /api/seed endpoint is idempotent — safe to call multiple times.

🔒

Secure Secrets Management

API keys and DB credentials stored in appsettings.Development.json which is excluded from Git via .gitignore.

04 — API Reference

REST Endpoints

POST /api/seed

Seeds the database with 30 movies and generates OpenAI embeddings for each. Idempotent — skips movies already seeded.

{  "seededCount": 30  }
POST /api/recommend

Accepts a mood string, generates an embedding, and returns Top 3 semantically similar movies with match scores.

Request body:

{
  "mood": "funny with a twist ending"
}

Response:

[
  {
    "title":       "Pulp Fiction",
    "genre":       "Crime / Drama",
    "description": "Interwoven stories of crime...",
    "score":       0.36
  },
  ...
]
05 — Setup Guide

How to Run Locally

1

Prerequisites

Install .NET 10 SDK, Node.js LTS, PostgreSQL 18 with the pgvector extension, and get an OpenAI API key.

2

Create the database

In PostgreSQL, create a database named moviedb. The table and pgvector extension are created automatically on first run.

3

Configure secrets

Create MovieApi/appsettings.Development.json with your connection string and OpenAI key:

{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Database=moviedb;Username=postgres;Password=YOUR_PW"
  },
  "OpenAI": {
    "ApiKey": "sk-..."
  }
}
4

Start the backend

$env:ASPNETCORE_ENVIRONMENT="Development"
cd MovieApi
dotnet run

API starts on http://localhost:5000

5

Seed the database

Call the seed endpoint once to populate all 30 movies with embeddings:

POST http://localhost:5000/api/seed
6

Start the frontend

cd movie-ui
npm install
npm run dev

UI opens at http://localhost:5173

The core of the recommendation is this SQL query using pgvector's cosine distance operator <=>: 

SELECT title, genre, description,
  CAST(1 - (embedding <=> @queryVec::vector) AS FLOAT8) AS score
FROM movies
ORDER BY embedding <=> @queryVec::vector
LIMIT 3
