01 — Overview

What Does This App Do?

You type a mood or feeling — like "something funny but emotional" or "thrilling with a twist" — and the app uses OpenAI's AI to understand the meaning of your words. It then searches 30 movies stored in PostgreSQL to find the ones whose descriptions are semantically closest to your mood, and returns the Top 3 with a % match score.

🔑 Key concept — Vector Embeddings: OpenAI converts text into a list of 1536 numbers (called a vector). Similar meanings produce similar vectors. The database finds movies whose vectors are closest to your mood vector using a mathematical formula called cosine similarity. This is how AI "understands" language.

29builder.Services.AddControllers();Registers controller support. This enables the MVC pattern so .NET knows to look for classes ending in Controller and route HTTP requests to them.

34–49using (var scope = app.Services.CreateScope()) { await db.Database.ExecuteSqlRawAsync(...) }Auto-creates the database table on every startup. 51app.UseCors();Activates CORS middleware in the request pipeline. The configuration was registered earlier — this line actually turns it on. Order matters: must be before MapControllers.

05 — Database Context

AppDbContext.cs — Line by Line

This file is the bridge between C# objects and the PostgreSQL database. It tells EF Core exactly which C# class maps to which table, and which property maps to which column.

MovieApi/Data/AppDbContext.cs Database Layer
1–3using Microsoft.EntityFrameworkCore; using MovieApi.Models; using Pgvector.EntityFrameworkCore;Imports. EF Core for database operations. Our own Movie model. Pgvector EF Core integration for the vector column type.
7public class AppDbContext : DbContextInherits from DbContext — the EF Core base class. This is what gives our class the ability to query the database, save changes, and run migrations.
9public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }Constructor. Receives database options (connection string, driver type) from dependency injection and passes them to the parent DbContext. This is how the connection string from appsettings.json reaches EF Core.
11public DbSet<Movie> Movies => Set<Movie>();Declares the Movies table. DbSet<Movie> represents a table in the database. You can query it like: _db.Movies.Where(...). The Set<Movie>() returns the EF Core set for that type.
13–37protected override void OnModelCreating(ModelBuilder modelBuilder)Configuration method called by EF Core when it builds the database schema model. This is where we customise how C# classes map to database tables/columns.
15modelBuilder.HasPostgresExtension("vector");Tells EF Core migrations that the pgvector extension is required. This ensures CREATE EXTENSION vector is included in any future migrations.
18entity.ToTable("movies");Critical mapping. By default EF Core would look for a table called "Movies" (PascalCase). But PostgreSQL uses lowercase "movies". This line fixes that mismatch.
19–23entity.Property(m => m.Title).HasColumnName("title");Column name mapping. Same reason as above — EF Core defaults to PascalCase column names like "Title", but PostgreSQL has "title". Each property is explicitly mapped to its lowercase snake_case column name.
24–26entity.Property(m => m.Embedding).HasColumnName("embedding").HasColumnType("vector(1536)");Vector column setup. Maps the Embedding property to the embedding column of type vector(1536). The 1536 is the dimension size — OpenAI's text-embedding-3-small always produces exactly 1536 numbers.
30–34modelBuilder.Entity<MovieQueryResult>(entity => { entity.HasNoKey(); });Keyless entity. MovieQueryResult is not a real table — it's just a C# class to hold results from a raw SQL query. HasNoKey() tells EF Core "this is not a real entity with a primary key, just a result shape."
06 — API Controller

MovieController.cs — Line by Line

This is the heart of the application. It contains the two API endpoints: one to seed movies into the database, and one to find movies matching your mood using AI.

MovieController.cs — Class Setup & Constructor API Controller
13[ApiController]Attribute that marks this class as an API controller. Enables automatic model validation, binding source inference (reads JSON body automatically), and proper error responses.
14[Route("api")]Sets the base URL prefix. All endpoints in this class start with /api. So [HttpPost("seed")] becomes POST /api/seed.
17–18private readonly AppDbContext _db; private readonly OpenAIClient _openAI;Private fields. Store references to the database context and OpenAI client. readonly means these cannot be reassigned after the constructor runs.
20–23public MovieController(AppDbContext db, OpenAIClient openAI) { _db = db; _openAI = openAI; }Constructor with Dependency Injection. .NET's IoC container automatically provides the AppDbContext and OpenAIClient when creating this controller — you never call new MovieController() yourself.
MovieController.cs — Helper Methods Helpers
GetEmbeddingAsyncEmbeddingClient client = _openAI.GetEmbeddingClient("text-embedding-3-small");Gets the embedding client for a specific OpenAI model. text-embedding-3-small is the model name — it converts text to 1536-dimensional vectors. It's fast and cost-effective.
OpenAIEmbedding embedding = await client.GenerateEmbeddingAsync(text);Calls the OpenAI API. Sends your text over the internet to OpenAI's servers. await means the code waits for the response without blocking the server. Returns an embedding object.
return embedding.ToFloats().ToArray();Extracts the actual numbers. ToFloats() gets the 1536 floating-point numbers. ToArray() converts from a span to a regular float[] array.
ToVectorString"[" + string.Join(",", floats.Select(f => f.ToString("G", CultureInfo.InvariantCulture))) + "]"Converts float[] to PostgreSQL vector format. pgvector expects vectors as strings like [0.123,0.456,...]. InvariantCulture is important — it ensures decimals use . not , regardless of what country settings the server has.
MovieController.cs — POST /api/seed Seed Endpoint
1[HttpPost("seed")]Registers this method as a POST endpoint at the URL POST /api/seed. Call this once to fill the database with movies.
2int count = 0;Counter to track how many new movies were actually inserted (vs skipped because they already exist).
3foreach (var (title, genre, description) in SeedMovies)Loops through all 30 hardcoded movies. Uses tuple deconstruction — each movie is a (string Title, string Genre, string Description) tuple.
4if (await _db.Movies.AnyAsync(m => m.Title == title)) continue;Idempotency check. AnyAsync runs SELECT EXISTS(...) in the DB. If a movie with the same title already exists, continue skips it. This makes the seed endpoint safe to call multiple times without duplicating data.
5float[] floats = await GetEmbeddingAsync(description);Calls OpenAI. Sends the movie's description text to OpenAI and gets back 1536 numbers that represent its meaning. This takes ~0.3 seconds per movie and costs a tiny fraction of a cent.
6–12_db.Movies.Add(new Movie { Title=title, ..., Embedding=new Vector(floats) });Creates a Movie object and adds it to the EF Core change tracker. new Vector(floats) wraps the float array into the Pgvector type that EF Core knows how to store in the vector(1536) column.
13await _db.SaveChangesAsync();Writes to the database. EF Core generates and runs the INSERT INTO movies (...) VALUES (...) SQL. Called inside the loop so each movie is saved before moving to the next.
14return Ok(new SeedResponse(count));Returns HTTP 200 with a JSON body like {"seededCount": 30}. If called again when all movies exist, returns {"seededCount": 0}.
MovieController.cs — POST /api/recommend Recommend Endpoint
1[HttpPost("recommend")]Registers this method as a POST endpoint at POST /api/recommend. Called every time the user clicks "Find Movies".
2public async Task<ActionResult<IEnumerable<MovieResult>>> Recommend([FromBody] RecommendRequest req)Method signature. async Task = asynchronous (can await). ActionResult<IEnumerable<MovieResult>> = returns either an HTTP error or a list of MovieResult objects. [FromBody] = reads the JSON request body and binds it to RecommendRequest.
3if (string.IsNullOrWhiteSpace(req.Mood)) return BadRequest(...);Input validation. If the user sent an empty mood, return HTTP 400 immediately. Prevents wasting an OpenAI API call on empty input.
4float[] floats = await GetEmbeddingAsync(req.Mood);Convert the user's mood to a vector. Calls OpenAI with the mood text (e.g. "funny with a twist"). Returns 1536 numbers representing the meaning of that mood.
5string vectorStr = ToVectorString(floats);Format for PostgreSQL. Converts float[] to the string [0.023,-0.14,...] that pgvector understands.
6var queryVec = new NpgsqlParameter("queryVec", vectorStr);Creates a SQL parameter. Using a parameterised query (@queryVec) instead of injecting the value directly into SQL prevents SQL injection attacks.
7–14_db.Database.SqlQueryRaw<MovieQueryResult>("""SELECT title, genre, description, CAST(1 - (embedding <=> @queryVec::vector) AS FLOAT8) AS score FROM movies ORDER BY embedding <=> @queryVec::vector LIMIT 3""", queryVec)The core AI search query. embedding <=> @queryVec::vector = cosine DISTANCE between each movie embedding and the mood vector (smaller = more similar). 1 - distance = cosine SIMILARITY (larger = more similar, shown as %). ORDER BY sorts smallest distance first. LIMIT 3 returns only the top 3 matches.
15return Ok(rows.Select(r => new MovieResult(r.Title, r.Genre, r.Description, r.Score)));Returns the results as JSON. Maps each raw DB row into a MovieResult DTO (Data Transfer Object) and sends them as an HTTP 200 response. The frontend receives a JSON array of 3 movies.

card JSX{results.map((movie, i) => ( <div className="card">... ))}Renders the result cards. .map() loops through the 3 movies. For each one, creates a card with the title, genre badge, description, rank number, and a match score progress bar.

STEP WHERE WHAT HAPPENS
1App.jsxUser types "funny with a twist ending" → clicks button → handleFind() runs.

3Program.csCORS middleware checks: is this request from localhost:5173? Yes → allow it.

8AppDbContext.csEF Core maps the raw SQL results into List<MovieQueryResult> C# objects by matching column names to property names.
